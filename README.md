# devsa-sessions

**Live build sessions from the DEVSA Discord, and what people made at them.**

Every few weeks, someone who has built or uses a tool worth knowing takes the stage on the [DEVSA Discord](https://www.devsa.community/discord) and installs it live, with everyone following along. No slides, no pitch: one tool, set up together, start to finish, with time for questions.

Each session gets a folder here with the setup steps, the links, and a list of what people built afterward. If you missed one live, the folder is enough to do it on your own.

## Build-and-tell Friday

Every Friday, #build-and-tell on the Discord asks what you built this week. Small counts; half-finished counts.

If what you posted is open source or has a public demo, give it a permanent home: add one line to [SHOWCASE.md](SHOWCASE.md) with a pull request. It's a good first open-source contribution if you haven't made one, and people looking at DEVSA's GitHub see what San Antonio builders are actually making.

## Want to run a session?

If you've built something, or you use a tool well enough to walk a room through installing it, ask in the Discord. A session needs one thing that installs and runs in about an hour, and a person who can answer questions about it. It doesn't need to be your own project, and it can't be a sales pitch.
